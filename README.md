# 墨劍訣 · Inkblade

水墨仙俠 × 觸控畫劍氣 × Roguelike 詞條升級 —— 玩法原型。

一句話定位:**用手指畫出劍痕,劍便沿著墨痕疾飛斬妖;斬妖聚道行、抽劍訣愈戰愈強,隕落轉世、永久修為愈滾愈猛。**

## 核心玩法
- **畫線飛劍**:按住畫出一道墨痕,鬆手後劍從起點沿整條軌跡飛到尾端,再依尾段方向續飛。可畫弧線繞後、折線轉向。
- **靈力 = 可畫長度**:畫線即時消耗靈力,滿靈力約可畫一道 700px 長痕;靈力見底墨痕轉金並凍結。短捷便宜、長弧昂貴,形成即時取捨。
- **敵人與靈石**:妖魔從四方湧向中央靈石,護不住即隕落。三種階級、隨波次增強。

## 成長系統
- **局內 · 三選一劍訣**:每升一重道行抽詞條(凡/靈/仙/絕四稀有度,加權)。一次連升多重時改為排隊逐張選,選完一張接著彈下一張,不會互相覆蓋而漏抽。
  - 多劍三陣型(互斥):分光劍(扇形)、並蒂劍(平行)、連珠劍(同痕前後單列)。
  - 效果:貫穿、御劍追魂(追蹤,降傷不暴擊)、裂空、迴劍、奪魄、養靈、靈台、劍匣。
  - 元素:業火符(赤焰灼燒)、寒霜訣(寒芒冰緩+霜傷)。顏色=元素效果,非預設塗裝。
- **跨局 · 轉世**(永久,存本機):隕落結算魂魄(斬妖 + 波次×5 + 道行×3);轉世閣永久修為(靈根/劍骨/神行/養氣/雙生)與秘傳解鎖(萬劍歸宗、御劍傳承);改版死亡畫面顯示成績、歷史最佳、下一個解鎖目標;一鍵轉世再戰。

## 掛機與商業化(示範)
- **閉關修煉(離線收益)**:離線依歷史最佳波次被動生魂魄,封頂 8 時(可擴),一鍵領取。
- **自動禦劍**:局內可切自動出劍,魂魄減半且不計歷史最佳。定位練功/無障礙。
- **課金商城(示範,不實扣款)**:靈石加值、換魂魄、閉關擴容、外觀(墨金劍痕)、修行月卡。原則:只賣加速與外觀,不賣數值唯一解。

## 響應式與版面
單一 HTML 於桌機、平板、手機直/橫置皆可用。HUD 採三欄 flex,窄螢幕時控制列自動換到第二排,不與左右資訊面板重疊;字級與間距全面 clamp() 縮放,按鈕維持 32–44px 觸控高度;畫布尺寸以實際佔位量測(非 innerWidth),搭配 dvh 與 visualViewport 監聽,手機瀏覽器工具列伸縮時不偏移;安全區(瀏海/圓角)以 env(safe-area-inset) 留白。

## 操作
- 滑鼠 / 觸控:按住拖曳畫劍痕,鬆手出劍。
- 暫停/繼續:右上「‖ 暫停」或 Esc / P。
- 自動禦劍:右上「⟳ 自動」或 A。自動出劍會依陣型補正瞄準,保證至少一把劍正對目標(扇形/平行偶數劍數不再左右夾空)。
- 音律開關:右上「♪ 音律」或 M。
- 音量設定:暫停畫面內有總音量、音樂、音效三支拉桿與靜音鈕,設定存本機;暫停時背景樂本來是完全靜止的,拖動音樂或總音量拉桿會暫時響起試聽,停手約 1.6 秒後再靜下。

## 音律與表現
- **背景樂**:`assets/audio/bgm/battle01.mp3` 循環播放。以兩個音訊元素做等功率(sin 曲線)交叉淡入淡出,曲末 2.8 秒與新一輪曲首重疊,接縫沒有空隙也不會有音量凹陷。開場淡入 1.8 秒,暫停淡出 0.5 秒後真正停止播放(不留背景解碼),繼續時從中斷處接回,隕落淡出 1.6 秒。不經 WebAudio,直接控制元素音量,`file://` 雙擊開啟也能正常播放。
- **音效**:WebAudio 程序化合成,零外部音檔。出劍(依劍痕長度變掃頻)、命中、暴擊、斬殺(依妖魔階級)、裂空、受傷、靈力不足、升級、換波磬鳴、隕落各有專屬音色,並經程序化脈衝殘響。選卡時背景樂照常演奏,不打斷戰鬥節奏。
- **打擊感**:命中震屏、暴擊/斬殺頓幀、全屏閃光三件套。
- **主角**:中央不再是靈石,而是持劍而立的劍客。原稿是一張白底剪影,離線沿劍軸以帶狀遮罩切成「身體」與「劍」兩張去背貼圖(握把留在身上,手不缺角),之後全靠程式讓它動:呼吸是整體微幅縮放與上下起伏;衣袂與髮絲是把貼圖逐列橫切、依高度給不同振幅的雙頻正弦位移,腳下振幅為零所以站得住;人物會轉身面向最近的妖魔,手中的劍繞握點指向目標,出劍時揮砍並帶身體前傾與弧形殘影。飛出去的劍也是同一把,依元素上色。法陣改為腳下的橢圓地陣。
- **水墨質感**:離屏預生成的宣紙纖維紋理、徑向漸層遠山暈染、斬妖留下的墨漬(緩緩滲淡)、毛筆提筆式收尾的拖尾與飛白、靈石雙環反向緩轉法陣(低血轉紅加速)、四邊暈影、波次落款題字。

## 效能
在 DPR=2 的高解析螢幕上,每幀塗滿六層全螢幕(宣紙紋理、四片遠山漸層、暈影)會把算圖成本壓垮 —— 1440×900 的 Retina 實測只有 6 fps。現行做法:

- **靜態圖層烘焙**:宣紙底、纖維紋理、遠山暈染合成到一張離屏畫布,四邊暈影合成到另一張,尺寸變動時才重烘;每幀只做兩次 `drawImage`。
- **墨漬蓋印**:斬妖的墨漬在產生當下直接印到底層畫布,不再逐幀重繪上百個 blob;每積 36 道洗一次紙,舊痕漸隱,畫面不會越打越黑。
- **移除 HUD 的 backdrop-filter**:面板疊在每幀重繪的畫布上,毛玻璃會逼 GPU 每幀重新模糊。
- **暫停/選卡降頻重繪**:此時畫面靜止,每四幀畫一次即可,省下全螢幕遮罩模糊。
- **HUD 差異更新**:數值沒變就不碰 DOM。
- **劍身貼圖化**:劍造型只跟劍氣寬度、元素、外觀有關,烘成一張貼圖,每把劍從「三個漸層 + 十幾段路徑」降成一次 `drawImage`。
- **自適應畫質**:跳過開場兩秒暖機,取 90 幀中位數,連兩個觀察窗都低於 ~45fps 才調降算圖解析度(2 → 1.5 → 1,只降不升)。用中位數而非平均,避免 GC 單點尖峰誤判。

### 診斷面板
按 <kbd>F</kbd>(或網址加 `?debug`)開啟右下角面板,顯示 fps、p50/p95/max 幀時間、由最短幀距推估的螢幕更新率、update 與 draw 各自耗時、目前 DPR 與畫布像素數、以及各類物件數量。開發端的無 GPU 測試環境量不到真機的合成成本,也看不出你的螢幕是不是 120Hz,這個面板是在實機上取數的依據。

同樣情境實測 6 fps → 60 fps,連續 60 秒推進到第五波維持 60 fps 不衰減。
