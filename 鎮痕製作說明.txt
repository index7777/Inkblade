請在目前《墨劍訣》專案中實作「鎮痕」技能的完整遊戲表現與 Slow Debuff。

先檢查現有專案：
1. 找出敵人移動速度、Buff/Debuff、技能效果、VFX、物件池、戰鬥傷害/狀態系統的位置。
2. 優先沿用現有架構，不要另外建立第二套 Buff 系統。
3. 不要直接修改敵人的基礎 MoveSpeed 永久數值。
4. Slow 必須透過現有 Modifier / StatusEffect / BuffDebuff 系統處理。
5. VFX 與 Gameplay 狀態必須分離。

==================================================
【技能名稱】
鎮痕

【定位】
痕系控制技能。
在敵人腳下形成一道鎮壓劍痕／符陣，使敵人移動速度降低。

【美術素材】
使用我提供的透明 PNG「鎮痕」作為主要地面素材。

這不是 UI Icon。
它是一個世界空間中的 Ground VFX / Decal / Sprite。

必須保持透明背景，不得產生黑底、白底或矩形底。

==================================================
一、Gameplay 邏輯
==================================================

建立或沿用：

StatusEffect:
ZhenHenSlow / 镇痕

建議資料化參數：

duration = 3.0 秒
slowPercent = 0.30
fadeOutDuration = 0.35
initialScale = 0.55
normalScale = 1.0

實際數字要做成 SkillData / Config / ScriptableObject / Resource，
不要 hardcode 在 VFX class。

Slow 計算：

FinalMoveSpeed = BaseMoveSpeed * (1 - SlowPercent)

例如：
slowPercent = 0.30
代表移動速度降低 30%。

注意：
不要：
enemy.moveSpeed *= 0.7

因為重複施放後會錯。

應使用：

Base Speed
× MoveSpeedModifiers

或專案現有 Modifier 系統。

==================================================
二、重複施放規則
==================================================

同一敵人再次受到「鎮痕」：

預設採：

Refresh Duration

也就是：
不疊加 Slow 強度，
只刷新持續時間。

例如：

第一次：
-30%
剩餘 1.2 秒

再次中鎮痕：

仍然：
-30%

但 duration 回到：
3.0 秒

不要變成：
-60%
-90%

除非目前技能資料明確設定可以 Stack。

結構上保留：

stackMode:
Refresh
Stack
ReplaceStrongest

目前鎮痕使用 Refresh。

==================================================
三、VFX 必須分成四個階段
==================================================

不要只 Spawn 一張 PNG 然後 Destroy。

要有：

APPEAR
→ LOCK
→ SUSTAIN
→ DISAPPEAR

--------------------------------
Phase 1：APPEAR / 落痕
--------------------------------

時間：
0 ~ 0.18 秒

鎮痕在敵人腳底瞬間生成。

Scale：

0.55
→
1.08

Alpha：

0
→
1

建議使用：
EaseOutBack
或相似曲線。

同時旋轉：

-4°
→
0°

讓它有「一道法陣突然壓到地面」的感覺。

這一刻可以額外產生：

一個非常快速的淡金圓環：

scale:
0.6 → 1.2

alpha:
0.7 → 0

duration:
0.18 sec

這個圓環是 Secondary VFX，
不是主素材。

--------------------------------
Phase 2：LOCK / 鎮壓
--------------------------------

時間：
0.18 ~ 0.35 秒

主圖：

Scale
1.08 → 1.0

做一次很短的「落地震盪」。

如果目前遊戲有 Camera Shake 系統：

只在重要技能／玩家可見時加入：

Amplitude 很小
Duration 約 0.08 秒

不要強烈震屏。

敵人模型可以有一次：

0.06 ~ 0.1 秒

很輕微的向下壓縮：

Y Scale:
1
→ 0.96
→ 1

如果遊戲角色系統不適合縮放，
則不要修改角色 Transform。

--------------------------------
Phase 3：SUSTAIN / 鎮痕持續
--------------------------------

持續到 Slow 結束。

主鎮痕不能完全靜止。

加入非常微弱的生命感：

Scale：

1.00
→
1.025
→
1.00

週期：
約 1.1 秒

不要快速呼吸。

Alpha：

0.88 ~ 1.0

微弱變化即可。

Rotation：

可以讓外圍 Secondary Ring：

0 → 360°

一圈約：
8 ~ 12 秒

主圖不要不停旋轉，
否則會像魔法陣，不像「痕」。

主圖應該保持基本固定。

==================================================
四、Slow 的視覺辨識
==================================================

玩家必須在 0.2 秒內看懂：

「這隻敵人被減速了。」

除了腳底鎮痕，再增加一個非常克制的效果：

Enemy Slow Indicator：

在敵人腳踝附近產生：
2~4 條淡灰／灰白色拖尾。

方向：
略微向後。

Alpha 很低。

或者：

每隔 0.6~0.9 秒
在敵人腳下向內縮一次淡薄圓環。

不要：
冰凍特效
藍色冰晶
西方魔法雪花

這是《墨劍訣》，不是冰系 Slow。

視覺語言應該是：

鎮
壓
沉
滯

而不是：
冰凍。

==================================================
五、顏色
==================================================

主要顏色沿用素材：

黑 / 灰
米白
非常少量暗金

Gold 只能作為：

鎮壓生效瞬間
符文
裂紋
能量邊緣

不要讓整張素材變成金色發光。

Glow 強度需要克制。

背景是水墨山水，
因此效果需要清楚，
但不能像 MMORPG 大型法陣一樣亮。

==================================================
六、敵人移動時怎麼處理
==================================================

鎮痕是「作用在敵人身上的痕」，
所以預設：

VFX Root 跟隨敵人的 Ground Position。

但：

不要直接 Parent 到角色骨架，
避免角色跳躍、旋轉、受擊動畫造成法陣傾斜。

實作：

每幀 / FixedUpdate / LateUpdate：

VFX.Position =
enemy ground anchor position

只同步 X/Y 或 X/Z 地面座標。

保持自己的世界旋轉。

如果目前遊戲是 2D：

Position =
enemy transform.position + groundOffset

Sorting Order：

Enemy Feet
<
ZhenHen
<
Enemy Body

讓鎮痕看起來是在腳下。

如果是 3D：

使用 ground decal / quad，
貼近地面，
避免 Z-Fighting。

YOffset 約：

0.01 ~ 0.03

依專案比例調整。

==================================================
七、尺寸
==================================================

鎮痕尺寸不能完全依敵人體型。

建立：

ZhenHenVisualRadius

一般敵人：

約為角色碰撞寬度的：
1.3 ~ 1.6 倍。

Boss：

不要直接跟 Boss 放大到非常巨大。

Clamp：

minScale
maxScale

例如：

visualScale =
Clamp(enemyRadius * factor, 0.85, 1.5)

讓 HUD/VFX 視覺保持一致。

==================================================
八、結束動畫
==================================================

Slow 結束前：

最後 0.35 秒：

Alpha：

1
→
0

Scale：

1
→
1.12

同時：

金色符文先消失，
再讓灰黑痕跡消散。

如果可以做到：

使用 Dissolve Material / Shader。

Dissolve：

0 → 1

從外圈往中心消失。

如果專案目前沒有 Dissolve Shader：

不要為了這個技能導入重型 Shader 系統。

使用：

Alpha Fade
+
Scale
+
Secondary particles

即可。

==================================================
九、死亡處理
==================================================

如果敵人在鎮痕期間死亡：

不要瞬間 Destroy VFX。

Gameplay Slow 立即解除。

VFX：

快速進入 DISAPPEAR。

duration：

0.15 ~ 0.25 秒

讓它自然消失。

==================================================
十、物件池
==================================================

不要頻繁 Instantiate / Destroy。

如果專案已有 ObjectPool：

使用現有 Pool。

需要 Pool：

ZhenHenVFX
ZhenHenRingVFX
SlowTrailVFX

如果同畫面可能出現大量敵人：

Secondary FX 要有最大數量限制。

主鎮痕不能被 Cull，
Secondary Particle 可以。

==================================================
十一、效能
==================================================

鎮痕可能同時存在很多個。

要求：

不在 Update 產生 GC Allocation。
不使用 LINQ in Update。
不每幀 Find/GetComponent。
初始化時 Cache Component。
使用 Object Pool。
粒子數量保持低。

如果有 30~50 個敵人同時中鎮痕，
VFX 必須仍能正常運作。

==================================================
十三、素材最好拆成 3 Layer
==================================================

如果目前只有一張完整 PNG，
先可以直接使用。

但程式結構請預留：

ZhenHen_Main
ZhenHen_Gold
ZhenHen_Particles

之後美術可以拆成：

Layer A：
灰黑主痕
→ 始終存在

Layer B：
金色符文／裂紋
→ 呼吸亮度

Layer C：
墨塵／碎屑
→ 出現與消失使用

這樣後續效果會比整張 PNG 一起亮暗自然很多。

==================================================
十四、強化表現：敵人真正變「沉」
==================================================

如果目前 Enemy Animator / locomotion 系統允許：

受到 Slow 時：

AnimationSpeed 可以非常輕微跟著 Slow 下降。

例如：

Movement Animation Speed：

normal = 1.0

30% Slow：

不要直接改成 0.7。

改成約：

0.88 ~ 0.92

因為如果動畫真的慢 30%，
會顯得非常卡。

只做視覺暗示即可。

Gameplay 仍按照真正 SlowPercent 計算。

==================================================
十六、完成驗收
==================================================

完成後請測試：

1.
一般敵人中鎮痕：
腳下立即出現效果。

2.
敵人移動：
鎮痕保持在腳底，不亂漂。

3.
Slow：
實際移速下降。

4.
再次受到鎮痕：
不重複乘算 MoveSpeed，
只刷新 duration。

5.
Slow 結束：
移動速度恢復原值。

6.
死亡：
狀態解除，
VFX 快速淡出。

7.
大量敵人：
30 個敵人同時鎮痕不產生明顯 GC Spike。

8.
Pause：
VFX 與遊戲 TimeScale 行為符合現有專案規範。

9.
畫面：
鎮痕可以明確看見，
但不遮擋敵人模型。

==================================================
十七、非常重要
==================================================

這個技能的視覺核心不是「爆炸」。

它應該讓玩家感覺：

敵人的腳下突然被某種劍訣留下的古老痕跡「鎮住」。

所以 Animation 節奏：

快落下
→ 重重鎮住
→ 安靜維持
→ 慢慢散去

不要：

不停閃爍
不停旋轉
大量粒子爆炸
高亮 Neon Glow
冰晶 Slow Effect

整體風格必須符合《墨劍訣》的：
古拙、修仙、殘篇、劍痕、暗金、沉靜感。

完成實作後：

3. 說明 VFX 尺寸、透明度、動畫時間在哪裡調整。
4. 說明鎮痕 PNG 要放在哪個 Asset 目錄。
5. 說明如何測試 Refresh Duration。
6. 不要修改與此技能無關的系統。
