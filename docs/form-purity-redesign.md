# 墨劍訣 · 類別純化(劍陣不夾帶他類)分析與重設計

> 原則:四大基礎類各自純粹,不互相夾帶;唯真意可跨類(它就是改寫流派)。

## 界線
- 劍陣 FORM:只管**排列/空間**——劍數分布、間距、角度、覆蓋形狀、隊列長度、位置。
- 劍行 MOMENTUM:飛行——速度/追蹤/折返/穿透/殘影。
- 劍痕 INTENT:命中後狀態——DoT/緩速/破甲/留白斬。
- 劍稟 CULTIVATION:基礎數值——傷/寬/靈力/暴/省魔/資源。

## 越界與衝突(現況)
| 位置 | 越界到 | 衝突 |
|---|---|---|
| 貫鋒·圓滿 回刺(pierceRecoil) | 劍行(折返) | 與貫鋒 tradeoff「不折返」矛盾;與歸鋒重疊(returnsLeft 歸屬/疊加);與引鋒末端延伸方向相反、順序未定義 |
| 齊鋒 基礎「自行追跡」+小成 volleyTighten | 劍行(追蹤) | 與引鋒 homing 衝突;SPEC 已規定執行劍令期間不追蹤 |
| 貫鋒·大成 破甲(pierceBreak) | 劍痕(減益) | 破甲應屬劍痕 |
| 散鋒·大成 殘鋒觸發墨痕(scatterEchoIntent) | 劍痕 | 讓劍陣去觸發劍痕 |
| 聚鋒 基礎「可折返」+圓滿 mergeHeavy(每折返+傷) | 劍行(折返) | 折返應只由歸鋒提供 |
| 散/齊/貫 tradeoff「此式不折返」 | 劍行 | 把折返屬性耦合在劍陣上 |

**回刺怎麼算 / 跟引鋒衝突嗎**:回刺=折返一次,用歸鋒/劍令的 cmdReachedEnd·returnsLeft。與引鋒不直接衝突(一個折返、一個前向追蹤),但**方向相反、執行順序未定義**,且與歸鋒 returnsLeft 歸屬不清 → 結論:回刺屬劍行,劍陣不該提供。

## 劍陣純化重設計(只用排列)
### 散鋒(扇)
- 小成:多分 2 道外緣劍(覆蓋更廣)。
- 大成:扇角 +30%,最外兩道射程更遠。
- 圓滿:環形陣(360° 散開)。
### 齊鋒(齊)
- 小成:並列間距自適應貼合敵群(**不追蹤**)。
- 大成:並列 +1 道(排面更寬)。
- 圓滿:雙排並列(縱深覆蓋)。
### 貫鋒(貫)
- 小成:前後間隔縮短、更密。
- 大成:一線加長,隊尾多接 1 劍(串更遠)。
- 圓滿:**滿貫**——一道劍令全部 N 把劍全中同一敵時,該敵額外受一次傷害 = N 把傷害總和 ×50%(彈「滿貫」字樣)。
### 聚鋒(聚)
- 小成:聚束更緊。
- 大成:命中同點多劍疊加(集中)。
- 圓滿:眾鋒歸一——收束成單一極粗劍痕,判定合一(**不靠折返**)。

## 連帶處理
- 折返屬性從劍陣移除(散/齊/貫/聚 都不再標「折返/不折返」);折返只由歸鋒提供。
- 齊鋒基礎描述移除「撲空的劍自行追跡」。
- 破甲改由劍痕負責(若要保留破甲,做成劍痕新技或蝕/鎮的一環)。

## 附:陣型如何套在手畫劍令上(關鍵)
陣型不是絕對形狀,而是**相對於「沿手畫劍令移動的中心點」的偏移**;中心忠實走玩家筆跡,並依路徑當下切線 `c.ang` 轉向。程式:`formationOffset()` 回 `{along(沿切線), side(法線), 角度}`,再由 `nx=c.x+cos(ang)*along−sin(ang)*side` 落地。

各式的路徑相對意義:
- 齊鋒 parallel:`side` 展開 → 垂直路徑的一字排,沿筆跡掃出帶狀。
- 貫鋒 inline:`along` 拉開 → 一列劍踩著筆跡魚貫而過。
- 散鋒 fan:角度展開 → 扇面騎著路徑。
- 聚鋒 merge:`along=side=0` → 一點描著筆跡。

純化里程碑以 along/side/角度/劍數 表示(皆路徑相對):
- 散鋒圓滿 環形陣 = 劍均布中心 360°(移動環,含身後覆蓋)。
- 齊鋒圓滿 雙排 = 兩條 side 排、along 前後錯開。
- 貫鋒圓滿 滿貫 = 全 N 劍命中同一敵 → 額外 50%×總傷(排列打滿的獎勵)。
- 聚鋒圓滿 眾鋒歸一 = 偏移趨近 0,合成單一極粗劍痕。

### 需夾限的邊界
1. 短筆跡:inline 隊列長於筆跡 → 尾端排到起點之前,靠接力補;需定義超出筆跡的擺放。
2. 急彎:side 落在彎內側可能交疊/出界 → 對 side 依曲率夾限,避免急轉角擠成一團。
