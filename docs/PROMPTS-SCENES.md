# 墨劍訣 · 場景素材提詞

每個檔案一則**完整且獨立**的提詞。直接整段複製貼給生圖工具即可,不需要與其他段落拼接,也不需要另外補風格前綴。

**共通技術規格**(不必寫進提詞,是給美術與工程對齊用的)

- `-bg` 為 2048×2048 不透明 PNG;中央直徑約 45% 的圓形區域必須是接近空白的淺色,戰鬥發生在那裡。
- `-near` 與 `-motes` 為透明背景 PNG。
- 所有素材不得出現人物、武器、文字、印章、簽名。
- 明度需保持中high,場上的墨獸是深色剪影,背景太暗會吃掉它們。

## 一、潑墨山谷

### `assets/scenes/pomo-valley-bg.png`

```
一幅中國水墨畫卷的全幅背景,正方形構圖,俯視一座潑墨山谷。

邊緣自然滲染出毛邊,可見宣紙纖維的吸水痕跡。
畫面四角墨色最重,往中央急速轉淡;正中央直徑約畫面 45% 的圓形區域幾乎全白,
只有極淡的一層灰調,像未落筆的宣紙。
底色是米白偏暖的老宣紙,帶細微紙纖維與淡淡的水漬痕。
單色水墨,只有黑、灰、米白三個層次,不要任何彩色。
平面構圖,沒有透視消失點,像一幅攤平的畫卷。
不要人物,不要武器,不要建築,不要文字,不要印章,不要簽名,不要邊框。
```
