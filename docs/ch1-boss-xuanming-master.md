# 第一章 Boss 母版：玄冥墨蛟

狀態：**第一章正式母版**  
關卡：潑墨山谷，第 60 波最終 Boss  
角色定位：污染畫卷的邪墨核心化成蛟龍；擊殺後畫卷才完全復原。

## 1. 正式視覺資產

- 遊戲主圖：`assets/boss/BOSS_XUANMING_idle_01.png`
- 設定母版：`assets/references/xuanming-mojiao-master.png`
- 舊 `assets/references/moshou-ref.png` 僅作歷史風格參考，不再決定第一關 Boss 的體型與攻擊方式。

母版辨識特徵：

- 盤成開口 C 形的蛇身墨蛟，頭部朝向中央玩家。
- 黑、灰水墨為主；紅色只用於雙眼與龜裂弱點核。
- 身體邊緣有乾筆飛白、墨霧與少量飛濺，但不可烘焙場景、地影或 UI。
- 戰鬥中每個可受擊狀態都必須看見紅眼與紅色弱點核；方向翻轉時弱點位置仍要一致。

## 2. 戰鬥硬規則（依現有文件）

1. 玩家固定在畫面中央，不使用走位、擊退或碰撞位移。
2. Boss 血條固定在畫面上方，不跟隨 Boss 移動。
3. Boss 從中央四周／八方現形，保留中央完整施法與飛劍迴旋空間。
4. 所有攻擊都必須先畫出墨氣預覽線；禁止無提示瞬發與不可破解的全屏傷害。
5. 威脅由飛劍處理：斬掉墨彈、打斷凝聚、命中紅核或清除召喚物，不要求玩家閃避。
6. 進入新階段時提供緩衝與免費洗點窗口；難度來自機制輪換，不靠純血量膨脹。
7. Boss 死亡為霧化消散，邪墨污染退去，畫卷切換至完好母版。

## 3. 基本循環

`墨氣湧動 → 墨形凝聚 → 盤旋壓境 → 攻擊 → 墨散如煙 → 換方向再現`

| 狀態 | 建議時間 | 畫面與玩法 |
|---|---:|---|
| 墨氣湧動 | 0.8–1.2 秒 | 畫面邊緣出現淡墨弧形預覽線，指出現形方位與攻擊路徑。 |
| 墨形凝聚 | 0.6–0.9 秒 | 霧團收束成墨蛟；凝聚點可被飛劍命中以延後或削弱本次攻擊。 |
| 盤旋壓境 | 1.5–2.5 秒 | 墨蛟沿中央外圈游走，頭始終朝向中央；紅核進入可輸出窗口。 |
| 攻擊 | 0.6–1.4 秒 | 執行衝墨、環浪或吐出墨核彈；所有危險路徑沿預覽線發生。 |
| 墨散如煙 | 0.7–1.0 秒 | 身體由尾至頭碎成霧絲，不留下永久污染或死亡墨漬。 |

## 4. 三階段攻擊模式

### P1：四象試鋒（100–70%）

- 從上、右、下、左四個方位輪流凝聚。
- **墨蛟衝墨**：一條由邊緣指向中央外圈的弧形預覽線；蓄力後沿線撲過，但在玩家外圈轉向，不穿越角色本體。
- **吐墨核**：發射 1 顆重型墨核彈，需 2 次飛劍命中才能抵銷。
- 目的：教玩家讀預警、用飛劍攔截，並辨識紅核輸出窗口。

### P2：八荒盤殺（70–40%）

- 出現方位擴充為八方，相鄰方位不可連續重複。
- **雙段游龍**：先沿外圈半環游走，再沿第二條預覽弧線折返；兩段間保留短暫反應窗。
- **環形墨浪**：由 Boss 向中央送出一圈帶缺口的墨彈；玩家用扇形／橫列飛劍清出安全缺口。
- 紅核只在轉向與吐息後短暫完全暴露，鼓勵穿透或引鋒直擊。

### P3：墨影歸淵（40–0%）

- 換位加快，但預警時間不得短於 0.65 秒。
- **殘影夾擊**：先後出現兩條不同方向的預覽線；第一條為淡墨殘影、第二條才是本體，兩者都能被飛劍削弱，不能同幀命中玩家。
- **萬墨歸核**：四周生成可破壞小墨團並向紅核匯聚；未攔截者為 Boss 回復少量護盾，不直接造成無提示傷害。
- 10% 以下進入決勝循環：現形更頻繁，但取消護盾回復，確保戰鬥能收束。

## 6. 驗收條件

- 玩家全程固定中央，Boss 與攻擊不把玩家推離中心。
- 每次傷害前都能看見方向與軌跡預警。
- 四方／八方現形時不遮住左上狀態、右上按鈕與上方 Boss 血條。
- 墨蛟、墨彈與背景污染能分層辨識；紅色只標示 Boss 弱點及必要戰鬥訊號。
- 消散後不留下永久墨漬；第 60 波 Boss 死亡後切換完好背景。
