# 墨劍訣 · Inkblade

## 設計綱要 Design System v2.0

> 畫外執筆,畫內御劍。

本文件是《墨劍訣》世界觀、美術與玩法的唯一基準。所有新設計、美術委製、AI 生成提詞,都以此為準。

---

## 一、核心理念

《墨劍訣》不是一款水墨風仙俠遊戲,也不是一款用毛筆戰鬥的遊戲。

它是一座由筆墨構築而成的**畫卷世界**。

玩家並不操控角色。玩家透過手指代筆,在畫卷上留下筆勢。畫中的修士感知這股劍意,御劍而戰。

- 玩家負責 **落筆**
- 修士負責 **出劍**

這條分工是整個專案的地基。任何設計若模糊了這條界線,就不屬於《墨劍訣》。

---

## 二、世界觀

### 傳說

相傳上古畫師以天地為紙、山河為墨,封存無數秘境於畫卷之中。每一幅畫卷都是一座完整的小世界。

然而隨著時間流逝,畫卷開始被**邪墨**侵蝕。畫境中的生靈逐漸化為**墨獸**。

玩家身為畫外的執筆者,能夠重新展開畫卷。每一次落筆,都能將自己的劍意傳遞給畫中的修士。

> 他不是你的分身。他只是聽見你的劍意。

### 世界規則

**畫外 —— 玩家所在之處**

玩家存在於現實。玩家永遠看不到自己的角色。玩家唯一能做的是:

- 落筆
- 引導劍勢
- 收集劍意
- 修復畫卷

玩家就是那支筆。

**畫內 —— 修士所在之處**

畫中只有一位修士。他不能離開畫卷,始終站在畫面的中心。他感知玩家的筆勢,並以御劍回應。

因此**角色不需要移動,真正移動的是劍**。這條規則直接決定了戰鬥設計:沒有走位、沒有閃避,只有落筆的角度、長度與時機。

### 敘事主軸

**每完成一關,不只是擊敗 Boss,而是修復了一幅畫。**

玩家推進的不是地圖,而是一卷卷逐漸恢復生機的畫卷。Boss 倒下的那一刻,污染退去、墨重新流回畫中、世界重新留白 —— 關卡結束的獎勵不是數值,是那幅畫恢復原樣的畫面。

這讓關卡、美術變化、劍意收集與世界觀綁在同一條線上,每一關都有明確的存在意義。

## 三、角色:畫中修士

### 定位

角色的正式稱呼是**畫中修士**,不是「男劍修 / 女劍修」。

**性別只是外觀。真正影響玩法的是劍意流派。**

```
畫中修士 A ──┐
             ├── 搭配「玄劍流」 ── 玩法完全相同
畫中修士 B ──┘
```

修士不是英雄單位,是**不同畫卷裡的人**。玩家不是在收集英雄,而是在修復畫卷之後,畫中的修士願意與你同行。

### 章節與修士

| 章 | 畫卷 | 修士 |
|---|---|---|
| 一 | 竹林卷 | 竹林女修 |
| 二 | 雪山卷 | 雪山男修 |
| 三 | 桃源卷 | 少年劍客 |
| 四 | 黃泉卷 | 老劍仙 |
| 五 | 敦煌卷 | 蒙眼修士 |

起手只有一位**無名修士**。之後每修復一幅畫卷,解鎖一位新的畫中修士。

這是**修復解鎖**,不是抽卡。

### 修士只保留

- 剪影
- 待機動畫
- 御劍姿勢
- **少量**天賦

### 天賦(刻意做小)

| 修士 | 天賦 |
|---|---|
| 白衣女修 | 飛劍速度 +5% |
| 黑衣男修 | 劍意獲取 +5% |
| 蒙眼劍客 | 暴擊率 +3% |
| 老劍仙 | 劍回收速度 +10% |

差異刻意壓在 3~10%,避免玩家為了數值被迫選特定修士。**選修士是選畫卷、選心情,不是選強度。**

## 四、唯一武器:墨劍(Master Sword)

### 規格

| 項目 | 內容 |
|---|---|
| 武器類型 | 飛劍(唯一武器) |
| 使用者 | 畫中修士 |
| 設定 | 畫外執筆,畫內御劍 |
| 特點 | 劍身如白玉,劍氣如墨 |
| 象徵 | 劍意不滅,畫卷長存 |

> 一劍出,墨痕萬里。無形無質,無鋒無芒。畫中方寸,已定乾坤。

母版檔案:`concept-art/master-sword-sheet.png`

### 不得更改

- 劍長
- 劍柄
- 劍首
- 劍尖
- 比例
- 配色

**所有遊戲素材都必須引用這把劍。** 從第一章到最後一章,劍永遠是同一把。

### 為什麼只有一把劍

多數遊戲的成長是換武器:

```
木劍 → 鐵劍 → 銀劍 → 神劍
```

《墨劍訣》不是。永遠都是墨劍,真正變強的是**御劍**。

玩家會覺得「我越來越會用這把劍」,而不是「我換了一把更好的劍」。

參照《鬼滅之刃》的日輪刀 —— 大家記得的是那把刀,一直變的是呼吸法特效。這裡也一樣:同一把墨劍,不同的劍意。

### 劍動畫規格

| 狀態 | 規格 |
|---|---|
| **待機** | 劍立於角色背後,微微浮動,每秒上下 2~4px,角度固定 |
| **飛行(普通)** | 保持同一把劍。不變形、不變大、不發光,只有速度感 |
| **飛行(高速)** | 同一把劍。增加殘影、增加飛白,不改造型 |
| **旋轉(環繞)** | 同一把劍繞身,軌跡以墨痕呈現 |
| **命中** | 劍保持原樣。命中瞬間**墨爆**,不是劍變成墨 |
| **返回** | 同一把劍,沿墨痕飛回,不改變任何外型 |

### 提詞規範

所有美術 / AI 提詞開頭都必須先寫一句:

> 使用《墨劍訣》Master Sword,不重新設計武器。

## 五、劍意:成長系統

玩家收集的是**劍意**。不是魔力、不是經驗值、不是筆意。

畫卷中的劍意以墨的形式存在,所以玩家吸收的是散落於畫中的墨,但真正得到的是劍意。

### 升級的不是武器,是御劍方式

不是這樣:

```
✗ +20% Attack
```

而是這樣:

| 劍意 | 效果 |
|---|---|
| **劍勢** | 增加速度 |
| **劍域** | 增加攻擊範圍 |
| **劍心** | 增加暴擊 |
| **劍魂** | 增加追擊 |
| **劍陣** | 增加分裂 |

全部都是御劍方式,不是武器能力。

### 章節推進 = 御劍能力推進

| 章 | 御劍 |
|---|---|
| 一 | 一劍 |
| 二 | 二段斬 |
| 三 | 三連斬 |
| 四 | 穿透 |
| 五 | 旋劍 |
| 六 | 劍陣 |
| 七 | 萬劍歸宗 |

劍沒有變,變的是劍勢。

---

## 六、劍意流派

流派才是真正的玩法差異,與修士是誰無關。

| 流派 | 特色 | 適用 |
|---|---|---|
| **玄劍流** | 劍速快、穿透 | 單體 Boss |
| **墨劍流** | 潑墨範圍、大範圍 | 清怪 |
| **歸劍流** | 飛出去、收回、多段命中 | 通用 |
| **劍陣流** | 繞身、防守、持續傷害 | 生存 |

世界觀適合做成**流派**,而不是**英雄** —— 因為玩家是畫外執筆者,畫中的人只是不同的畫中修士。

## 七、玩法

### 核心鏈路

```
玩家(執筆)
   ↓ 畫出劍令
畫中修士
   ↓ 御劍
劍意
   ↓
墨痕
```

玩家畫出的每一筆,不是生成墨,而是**生成一道劍令**。修士收到劍令後御劍。

### 落筆

- 按住畫出一道墨痕,鬆手後劍沿整條軌跡疾飛,再依尾段方向續飛
- 可畫弧線繞後、折線轉向
- **靈力 = 可畫長度**:畫線即時消耗靈力,滿靈力約可畫一道 700px 長痕;靈力見底墨痕轉金並凍結
- 短捷便宜、長弧昂貴,形成即時取捨

角色不動,所以所有戰術都壓縮在「怎麼落這一筆」上。

### 局內成長:三選一劍訣

每升一重道行抽詞條(凡 / 靈 / 仙 / 絕四稀有度,加權)。一次連升多重時排隊逐張選,不會互相覆蓋。

- 三種陣型互斥:分光劍(扇形)、並蒂劍(平行)、連珠劍(同痕前後單列)
- 效果:貫穿、御劍追魂、裂空、迴劍、奪魄、養靈、靈台、劍匣
- 元素:業火符、寒霜訣 —— 顏色 = 元素效果,非預設塗裝

### 跨局成長:轉世

隕落結算魂魄(斬妖 + 波次×5 + 道行×3),於轉世閣兌換永久修為與秘傳解鎖。

### 關卡

每一關是一幅畫卷。推進的單位是畫卷,不是地圖。Boss 倒下即畫卷修復,並解鎖該卷的修士。

## 八、美術

### 三大原則

**1. 世界是畫**

所有背景都必須讓玩家覺得「這是畫出來的」,而不是「這是真實地形」。

山、水、樹、石、雲、橋都保留毛筆筆觸與宣紙肌理。**可以大量留白,不需要畫滿。**

**2. 角色是人**

角色不是水墨,角色保持乾淨。他是畫中的生命,不是背景的一部分。

- 臉部乾淨
- 輪廓清楚
- 白衣為主
- 灰黑點綴
- 不使用大量墨暈覆蓋角色

**角色要永遠是畫面最容易辨識的元素。**

**3. 劍永遠是主角**

不是法杖、不是毛筆、不是法術。所有攻擊都由飛劍完成。

### 畫境

每一關都是不同的畫境,**不會一直都是黑白**:

- 潑墨山谷
- 青綠山水
- 雪墨寒林
- 桃源秘境
- 江南煙雨
- 黃泉殘卷
- 山海異錄
- 敦煌壁境

每張畫都有不同的墨色、筆法、留白、氣氛、色彩。

## 九、特效語言(FX Language)

這是整個遊戲最重要的部分。

| 情境 | 表現 |
|---|---|
| **劍飛行** | 飛劍本體保持俐落,只保留極細的墨色拖尾。不要誇張光效 |
| **劍命中** | 墨炸開。不是火焰、不是光爆,而是一滴墨落入宣紙,向四周自然暈開 |
| **劍穿透** | 留下乾淨俐落的劍痕。筆勢要有起筆、行筆、收筆、飛白,不是一條發光直線 |
| **暴擊** | 潑墨。像濃墨被狠狠甩到宣紙 |
| **範圍技能** | 不是元素爆炸,而是一幅畫突然被重重落下一筆,墨跡迅速向四周擴散 |
| **怪物死亡** | 不是爆炸,而是**化墨**。墨滴散落,留下劍意 |
| **Boss 死亡** | 畫卷恢復。污染退去,墨重新流回畫中,世界重新留白 |

---

## 十、怪物:墨獸

怪物不是妖怪,而是**被污染的畫靈**,稱為**墨獸**。

牠們本來也是畫的一部分,只是被邪墨侵蝕。因此死亡後重新回到墨。

這個設定同時解釋了為什麼牠們湧向中心、為什麼死亡表現是化墨、為什麼玩家收到的是劍意。

## 十一、UI

UI 不是科技介面,而是:

- 宣紙
- 印章
- 卷軸
- 硯台
- 墨條
- 朱印

**所有介面都像一幅作品的一部分,不是覆蓋在遊戲上。**

## 十三、黃金準則(Golden Rules)

1. 玩家不是劍修,而是畫外執筆者。
2. 畫中修士不移動,只御劍。
3. 所有攻擊都由飛劍完成。
4. 所有特效都來自劍,而不是魔法。
5. 墨不是武器,而是劍勢留下的痕跡。
6. 每一關都是一幅不同的畫卷,而不是同一種水墨背景。
7. 角色永遠乾淨,場景負責展現水墨意境。
8. 任何新設計都要回答一個問題:**它是否符合「畫外執筆,畫內御劍」?** 如果不能,就不屬於《墨劍訣》。

## 十四、現況對照

原型 `inkblade.html` 與本綱要的落差:

### 已符合

| 項目 | 狀態 |
|---|---|
| 畫外執筆,畫內御劍 | 落筆生成劍令,修士立於中心不移動 |
| 角色不移動 | 修士固定於畫面中心 |
| 所有攻擊由飛劍完成 | 無其他攻擊手段 |
| 靈力 = 可畫長度 | 已實作即時取捨 |
| 命中墨爆、斬殺化墨 | 已實作墨暈與墨漬滲染 |
| 劍痕有起筆行筆收筆飛白 | 拖尾為毛筆提筆式收尾,末段帶飛白 |
| 角色乾淨、輪廓清楚 | 剪影去背,不被墨暈覆蓋 |
| UI 宣紙質感 | 宣紙底、朱印色、卷軸式面板 |

### 待調整

| 項目 | 落差 | 方向 |
|---|---|---|
| **武器造型** | 目前用的是修士剪影上切下來的劍 | 改用 Master Sword 母版,建立唯一基準 |
| **成長命名** | 目前是「道行 / 詞條」 | 改為劍意:劍勢、劍域、劍心、劍魂、劍陣 |
| **怪物命名** | 目前是「妖魔」 | 改為墨獸;死亡表現改為化墨留下劍意 |
| **關卡結構** | 目前是無盡波次 | 改為畫卷章節制,Boss 倒下即畫卷修復 |
| **背景** | 目前是單一宣紙底 | 每卷不同畫境,不再一直是米白 |
| **流派** | 未實作 | 玄劍 / 墨劍 / 歸劍 / 劍陣四流派 |
| **修士收藏** | 未實作 | 修復畫卷解鎖,附小幅天賦 |
| **元素系統** | 目前有業火 / 寒霜 | 需檢視:是否違反「所有特效都來自劍而非魔法」 |

> 最後一項值得討論。業火與寒霜在現行原型是「劍的元素」,但依黃金準則第 4 條,火與冰更接近魔法。可能的收斂方向是改為劍意的表現:焦墨(灼)、凍墨(緩),讓效果仍在墨的語彙之內。

## 十五、資產規範

```
assets/
  art/
    hero-body.png        畫中修士剪影(去背,不含劍)
    hero-sword.png       墨劍(去背,握把在左、刃朝右)
  audio/
    bgm/                 背景樂
    sfx/                 音效(現行為程序化合成)
concept-art/
  master-sword-sheet.png 墨劍母版設定表 ← 唯一武器基準
  cultivator-01-source.png 修士原稿
docs/
  DESIGN.md              本文件
```

**規範**

1. 任何新的劍素材,一律以 `master-sword-sheet.png` 為唯一基準,不得更改造型與比例。
2. 修士素材一律去背、乾淨剪影,不含劍(劍另存,才能獨立御劍)。
3. 提詞開頭固定寫「使用《墨劍訣》Master Sword,不重新設計武器」。
4. 場景素材以畫卷為單位分目錄,每卷自帶墨色與色彩設定。
