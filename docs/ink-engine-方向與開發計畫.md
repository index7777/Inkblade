# 墨劍訣 · Ink Engine — 技術方向與開發計畫

> 建立日期:2026-08-07
> 本文記錄「Ink Engine(水墨特效引擎)」的核心構想、分工、技術架構與後續開發待辦。這是《墨劍訣》被認定為最值得投入的核心技術方向。

---

## 1. 核心決策(推翻舊方案)

- **舊想法(已放棄)**:大量生成 FX 用的 PNG(劍氣、命中、爆裂序列幀)。
- **新方向(採用)**:FX 完全程序化(Canvas 即時生成),幾乎不再生成任何 FX 圖片。
- **一句話**:背景是「紙」,所有特效是「墨」。用水墨本身的語言做遊戲,而不是模擬它。

## 2. 三個關鍵洞察

1. **限制即風格**:水墨的本質就是「留白 + 黑墨 + 飛白 + 毛邊」,觀者腦補是這個畫種內建的機制。不做紙滲、不堆半透明貼圖,反而更純粹、更高級。
2. **分工正確**:靜態資產(定稿後不變)適合 AI 生圖;FX(每幀變、綁遊戲狀態)必須程式生成。兩者各取所長。
3. **劍氣 = Bezier + Brush Texture,不是圖片**:玩家畫的軌跡本就是一條 Bezier,把它當筆劃「刷」出來,劍氣即真毛筆感、每發獨一無二。等同《Okami》的靈魂,但 2D Canvas 即可達成,無需 3D sumi-e shader。

## 3. 生產分工

| 交給 AI 生成(靜態) | 交給程式 / Canvas(動態) |
|---|---|
| 角色、武器、怪物、Boss、背景、UI | 所有 FX:劍氣、命中、爆裂、暈染、Boss 出招、死亡等 |

風格鎖定:AI 生圖時務必把 `ink-wash / sumi-e / 留白 / 墨線 / 飛白` 鎖進提詞,確保靜態與動態同一種水墨語言,避免「寫實立繪 + 抽象墨 FX」的違和。

## 4. Ink Engine 架構

### 4.1 五種 Primitive(所有特效的基本粒子)
- **Brush Stroke(筆劃)**:沿 Bezier 等距「蓋章(stamp)」,壓感兩端漸收(寬度/濃度)。
- **Ink Drop(墨滴)**:單枚帶輕微擴散的圓墨點。
- **Splash(潑墨)**:自一點噴出數條短 Bezier + 濺點。
- **Dry Brush(飛白)**:同筆劃路徑但降低蓋章密度、隨機漏白。
- **Diffusion(暈染,可選)**:離屏低解析度模糊 / alpha 外擴模擬。最耗效能,可開關。

### 4.2 資料驅動:技能 = 配方表
技能不寫死,而是一張 Primitive 組合配方(建議 JSON),策劃可純調表、不碰引擎;新技能=新配方,美術零額外成本。

```
御劍斬     = [Brush×1, DryBrush×2]
萬劍訣     = [Brush×30, InkDrop×20]
破軍       = [Brush×1, Splash×1]
Boss 死亡  = [Splash×1, InkDrop×50]
```

### 4.3 技術落地要點
- **核心 = brush stamp**:程序化生成少量筆刷 alpha 紋理(帶纖維與濃淡),一次生成重複使用;之後一切都是「沿路徑蓋章」。
- **混色**:走 multiply / darken 疊在紙背景上,墨色自然加深。
- **路徑**:劍氣用玩家畫線的 Bezier(起點→控制點→終點)。
- **烘焙**:靜止的墨痕烘焙到離屏 canvas 只畫一次,不逐幀重繪。

## 5. 風險與注意(決定成敗,但不影響方向)

1. **FX 先溝通、再好看**:劍氣/命中/出招必須一眼讀出判定範圍與時機。建議 FX 分兩層——(a) 清晰的 gameplay 墨形,(b) 純氛圍暈染(可依效能開關)。
2. **效能**:數百上千 stamp/幀吃 fill-rate,手機尤甚。對策:筆刷紋理只生成一次、物件池(勿逐幀 new)、靜止墨痕離屏烘焙、Diffusion 走低解析度。持續用 fps-check 盯。
3. **風格接縫**:AI 靜態資產必須也是水墨畫感,否則與墨 FX 違和。
4. **筆刷真實度**:2D stamp 能「很像毛筆」;要「真宣紙運筆」的濕邊與纖維,長期可上 WebGL/shader。先用 2D 做出玩法手感,不過早 over-engineer。

## 6. 後續開發待辦(Roadmap)

### 階段一:Ink Engine PoC(獨立驗證)
- [ ] 程序化生成筆刷 alpha 紋理(2–3 種)。
- [ ] 實作五個 Primitive:Brush Stroke / Ink Drop / Splash / Dry Brush / Diffusion。
- [ ] 建立配方表格式(JSON)與「配方→特效」的播放器。
- [ ] 示範技能:御劍斬 / 萬劍訣 / 破軍 / Boss 死亡。
- [ ] 滑鼠/觸控畫線 → Bezier + brush 即時刷出劍氣。
- [ ] 疊 FPS 顯示與物件池,驗證效能。
- [ ] 產出獨立 `ink-engine.html` 作為技術 demo。

### 階段二:整合回《墨劍訣》
- [ ] 以 Ink Engine 取代現有所有 Canvas FX(劍氣拖尾、命中、爆裂、灼燒/冰緩、升級、隕落)。
- [ ] 把現有詞條/技能改寫成配方表驅動。
- [ ] 元素(業火/寒霜)以配方 + 色板變體表達,不新增貼圖。

### 階段三:美術與效能升級(視需要)
- [ ] WebGL/shader:紙張纖維、濕度擴散,提升筆刷天花板。
- [ ] FX 兩層(溝通層 / 氛圍層)分離與品質開關。
- [ ] 手機端效能實測與降級策略。

### 待決定
- [ ] 配方表的完整 schema(參數:數量、路徑來源、色板、壽命、隨機種子…)。
- [ ] Diffusion 預設開或關(依主流機型效能)。
- [ ] 靜態資產的 AI 生圖風格基準(建立統一風格提詞範本)。

## 7. 為什麼值得投入
這套 Ink Engine 不只是省 PNG 成本——資料驅動讓新技能近乎零美術成本、全遊戲 FX 維持同一種水墨語言、劍氣隨玩家運筆獨一無二。這是《墨劍訣》最大的辨識度與技術護城河,也是最值得優先投入的方向。
