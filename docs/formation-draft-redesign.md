# 劍陣改為「開局四選一・鎖定一路」設計規格

> 狀態:**設計定案,尚未實作**(排在架構 Stage 2b 收段落之後)。使用者定案 2026-08-11。
> 相關:`docs/momentum-formation-and-anchor.md`(劍行綁劍陣)、`data/game-config.js`(INSIGHTS/runtime)。

## 一、問題(現況 bug)

`canOfferInsight` 對劍式(FORM)沒有任何「只能選一個陣型」的限制:只要該陣 `rank < maxRank(5)` 就會一直被抽到。於是先學貫鋒(貫1)、再學扇鋒(扇1)→ 兩個陣型同時留在 `ranks`、也同時繼續進卡池:

- 卡池被稀釋、流派混亂(多個陣型各自低階)。
- 跨陣型污染:例如齊鋒學到引鋒後切扇陣,引鋒殘留造成扇型動作詭異(見 #34/#36 的補丁)。

## 二、設計(定案:commit 模型)

1. **開局四選一(強制)**:一局開始、進入戰鬥前,強制從 散鋒/齊鋒/貫鋒/聚鋒 四陣**選一個**。
2. **鎖定一路**:該陣即為本局唯一陣型,**不能再換**;其餘三陣整局**永不出現**在卡池。
3. **陣等級 = 該陣的階**:選定的陣型隨後在**正常三選一卡池**中出現「該陣 +1 階」升級卡(2→5),其他三陣不出現。「劍陣等級」就是這一陣的 rank,不再有跨陣型分裂。
4. **專屬劍行乾淨**:只有該陣的專屬劍行(散→疾影 / 齊→引鋒 / 聚→歸鋒 / 貫→定鋒)會被提供。
5. **紅利**:一局只有一個陣型 → 跨陣型污染整類 bug 根絕(formationLock 補丁降為雙保險)。

## 三、實作草案(config + 主檔)

### config(`data/game-config.js`)
- `createRunState`:開局**不預設 formation**(或標記 `formationChosen=false`)。
- `canOfferInsight`:加規則——
  - 若尚未選陣(開局四選一由主檔專屬流程處理),一般三選一**不提供任何 FORM**(避免和開局draft重複)。
  - 若已選陣(`state.activeForm` 已定),**只有該 FORM id 可被提供**,其他三個 FORM 一律 `return false`。
- 換陣相關:`recomputeForFormation` 的「切陣停用不符劍行」在 commit 模型下不會被觸發(沒有切陣),保留為守門即可。

### 主檔(`inkblade.html` / 遷移後為 `src/`)
- **開局四選一 UI**:run start(過場後、生怪前)彈出專屬 4 選 1(沿用卡片樣式,顯示四陣 + 各自 tradeoff),**必選、不可略過、不可 reroll**(或給一次 reroll,待定)。選定 → `applyInsight(該FORM)` → 設 formation → 進入戰鬥。
- 之後正常三選一照跑;該陣升級卡由 config 規則自然進池。
- 既有 formationLock 補丁(引鋒限 parallel 等)保留為雙保險。
