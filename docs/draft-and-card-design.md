# 墨劍訣 · 抽卡權重與卡片呈現(設計方向)

> 狀態:**待確認/待實作**(尚未改 config 或主檔)。此為使用者定的方向,先記錄。

## 1. 卡片用「類型」呈現,不用顏色分階
- 卡片標示所屬**類型**:劍陣 / 劍行 / 劍痕 / 修為 / 真意(取代現在的稀有度「初悟/明悟…」色階文字)。
- 稀有度退回純後端(隱藏),不在卡上顯示。
- 真意可保留一個醒目的特殊框(它確實稀有且改流派)。

## 2. 抽卡權重:由「投入」決定,幫玩家滾到滿階
- **已抽過、未滿階**的能力 → 加權,讓它更常再出現,順利練到滿階(滿階才進境界)。
- **沒抽過**的 → 一般基礎權重(仍能開新流派)。
- **移除**現行「同稀有度每 3 次 ×0.75 衰減」(那是打散,與此方向相反)。
- 待敲定數字:已投入能力加權倍率(暫議 ×3,且每多一階再 +0.5 倍)—— 未定案。

## 3. 真意:低機率大獎、真的強
- 維持很低基礎權重(稀有),不吃「滾滿階」加權(本就 1 階)。
- 抽到即為流派改寫級強力(名副其實)。
