# 墨劍訣 · 劍行/劍痕/劍稟 類別純化審查

> 尺:劍行=飛行(速度/追蹤/折返/穿透/殘影);劍痕=命中後狀態(DoT/緩速/破甲/留白斬);劍稟=基礎數值/資源(傷/寬/靈力/暴/劍數/省魔)。唯真意可跨類。

## 劍行 MOMENTUM
| 位置 | 問題 | 建議 |
|---|---|---|
| 破墨(整技) | 命中潑墨波及=命中後範圍效果,偏劍痕;可用「勢=衝擊」辯護 | **你決定歸類**:留劍行(視為衝擊力道)或移劍痕(命中AoE) |
| 歸鋒·大成 returnSeek | 回程探敵=追蹤,踩引鋒 | 歸鋒回程純原路倒走;追蹤只給引鋒。大成改「回程再+速/多一趟」 |
| 疾影·圓滿 | (提案曾寫殘影觸發劍痕) | 收回:殘影只獨立命中,劍痕由全域決定 |

## 劍痕 INTENT
| 位置 | 問題 | 建議 |
|---|---|---|
| 斷意(斷痕)·每階 +暴擊率 | 暴率=劍稟數值,且與凝神重複 | 斷痕只管留白斬痕(固定額外傷/短減益),與暴擊脫鉤;暴率交凝神 |
| 鎮痕·圓滿 rootWhiteCut | 借用白斬(斷痕招牌) | 改鎮痕自有:定身結束擴散鎮痕/爆鎮範圍傷 |
| 回元(整技) | 資源型=劍稟 | 移入劍稟 |

## 劍稟 CULTIVATION
| 位置 | 問題 | 建議 |
|---|---|---|
| 開匣·大成 +劍速 | 劍速=劍行 | 改「再存/再+1劍」 |
| 斂鋒·大成 +劍速 | 劍速=劍行 | 改「更省劍意/擦邊命中」 |
| 展鋒·圓滿 strokeLingers 滯留再傷 | 持續傷=劍痕 | 改純幾何(判定再放大/擦邊也算命中) |
| 養鋒·圓滿 edgeMoment 每5秒必暴 | 暴擊 proc=凝神 | 改純傷害(劍傷+X%/對滿血敵加傷) |
| 納息、凝神 | 乾淨 | — |

## 跨類重複值正規化
- 暴擊率:斷意 + 凝神 + 養鋒圓滿 → **只留凝神**。
- 劍速:疾影 + 開匣大成 + 斂鋒大成 → **只留疾影**。
- (劍數 swordCount 由 FORM 排列與 開匣/萬劍 共用,屬容量,可接受;但需一致定義。)
