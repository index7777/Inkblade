# 墨劍訣 · 技能文案規範

> `data/game-config.js` 的 `validateConfig()` 會依本文件的規則做機器檢查。
> 改文案前先看這裡;改規則要同時改 config 裡的常數。

## 一、用語定案(不再變動)

| 概念 | 定案用語 | 已廢棄 |
|---|---|---|
| 生命 / 本體存續 | **神識** | ~~靈元~~ |
| 施法資源 / 可畫長度 | **劍意** | ~~靈力~~ |
| 等級 | **道行 · N 重** | — |
| 升級三選一 | **悟道** | — |
| 永久強化 | **轉世閣** | — |

`inkblade.html` 與 `data/game-config.js` 一律用定案欄。舊設計文件(`DESIGN.md`、
`ROADMAP-combat-v2.md`、`DESIGN-combat-v2.md`)與 `CHANGELOG.md` 屬歷史紀錄,
保留當時的寫法不回頭改;新增段落請用定案用語。

## 二、悟道卡片說明的長度上限

- 上限 **22 個全形字**(`String.length`),常數在 `data/game-config.js` 的 `DESC_MAX`。
- 這是實測「固定尺寸卡片最窄版面」的容量。超過會被裁掉,不是換行。
- **超標一律縮短文案,不得縮小字級** —— 字級是三張卡共用的視覺節奏,動一張就全歪。
- `validateConfig()` 會把超標項目列成 error:`說明超出 22 字(N):<名稱> 需縮短文案`。

### 縮短的優先順序

1. **先砍情境描寫,保留機制**。玩家在選卡當下要判斷的是數值與規則,不是意境。
   - ✗ `萬鋒同歸一念:增三劍、開六席劍匣,但單劍傷害降低。`(26 字)
   - ✓ `增三劍、開六席劍匣;單劍傷害略降。`(17 字)
2. **合併重複主詞**。`所有劍必定折返,回程傷害更高。` 不需要再寫一次「劍去無聲,歸時見鋒」。
3. **量詞用「略/大幅」取代具體數字**。具體數值由 UI 另外顯示,寫進說明會與平衡調整脫節。
4. 名字本身已經表意的,說明不要再複述一次名字的意思。

意境不是不要,而是放在**名稱**與**符文**(`name` / `rune`)上 —— 那兩處沒有長度壓力。

## 三、其他文案欄位

- `name`:2–4 全形字,對仗優先。
- `rune`:1 字,取 `name` 中最有代表性的那個字。
- 轉世閣 `description`:目前無硬上限(版面可換行),但仍建議 ≤ 24 字,句式統一為
  「每階令……」或「開局……」。
