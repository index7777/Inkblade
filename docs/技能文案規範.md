# 墨劍訣 · 技能文案規範

> `data/game-config.js` 的 `validateConfig()` 會依本文件的規則做機器檢查。
> 改文案前先看這裡;改規則要同時改 config 裡的常數。

## 一、用語定案(不再變動)

| 概念 | 定案用語 | 已廢棄 |
|---|---|---|
| 生命 / 本體存續 | **神識** | ~~靈元~~ |
| 施法資源 / 可畫長度 | **劍意** | ~~靈力~~ |
| 等級 | **道行 · N 重** | — |
| 升級三選一 | **悟道** | — |
| 永久強化 | **轉世閣** | — |

`inkblade.html` 與 `data/game-config.js` 一律用定案欄。舊設計文件(`DESIGN.md`、
`ROADMAP-combat-v2.md`、`DESIGN-combat-v2.md`)與 `CHANGELOG.md` 屬歷史紀錄,
保留當時的寫法不回頭改;新增段落請用定案用語。

## 二、悟道卡片說明的長度上限

- 上限 **22 個全形字**(`String.length`),常數在 `data/game-config.js` 的 `DESC_MAX`。
- 這是實測「固定尺寸卡片最窄版面」的容量。超過會被裁掉,不是換行。
- **超標一律縮短文案,不得縮小字級** —— 字級是三張卡共用的視覺節奏,動一張就全歪。
- `validateConfig()` 會把超標項目列成 error:`說明超出 22 字(N):<名稱> 需縮短文案`。

### 縮短的優先順序

1. **先砍情境描寫,保留機制**。玩家在選卡當下要判斷的是數值與規則,不是意境。
   - ✗ `萬鋒同歸一念:增三劍、開六席劍匣,但單劍傷害降低。`(26 字)
   - ✓ `增三劍、開六席劍匣;單劍傷害略降。`(17 字)
2. **合併重複主詞**。`所有劍必定折返,回程傷害更高。` 不需要再寫一次「劍去無聲,歸時見鋒」。
3. **量詞用「略/大幅」取代具體數字**。具體數值由 UI 另外顯示,寫進說明會與平衡調整脫節。
4. 名字本身已經表意的,說明不要再複述一次名字的意思。

意境不是不要,而是放在**名稱**與**符文**(`name` / `rune`)上 —— 那兩處沒有長度壓力。

## 二之二、「效果」模式的版面上限

劍訣註解可切換 **文字 / 效果**(靜觀設定)。效果模式的文字**不是手寫的**,由
`data/game-config.js` 的 `runtime.effectLines(id)` 從宣告式 `effects` 直接產生 ——
所以它永遠跟實際數值一致,不會脫節。

`validateConfig()` 會用**同一份產生器**做版面檢查(兩者同源,驗證不會跟畫面脫鉤):

| 限制 | 值 | 常數 |
|---|---|---|
| 單行寬度 | 9.2 | `EFFECT_MAX_W` |
| 行數 | 4 | `EFFECT_MAX_LINES` |

寬度單位:**全形字算 1、半形字算 0.55**(`textWidth()`)。這個 9.2 是量出來的 ——
最窄的機型(360px)卡片只有 109px 寬,扣掉內距約 95px 可用。

超標時 `validateConfig` 會回報,例如:
```
效果單行過寬(13.05/9.2):鎮痕 「敵方每秒 −1.5,續 2.6 秒」
```

### 超標的處理順序

1. **拆行**,不要塞在同一句。狀態類效果就是這樣拆的:
   - ✗ `敵方每秒 −1.5,續 2.6 秒`(13.05)
   - ✓ `每秒 −1.5`(5.2)+ `續 2.6 秒`(4.8)
2. **縮短標籤**,改 `EFFECT_LABEL` 的對照(例:`斬妖回劍意` → `回劍意`、`暴擊倍率` → `暴擊倍`)。
   標籤是共用的,改一次全部卡片受惠。
3. **砍掉次要資訊**。層數上限這種細節放在文字模式的說明就好,效果模式不列。
4. 最後才考慮縮字級 —— CSS 已經依行數自動降階(`.cfx.n3` / `.cfx.n4`),不要再手動加。

### 現況

24 張卡在 360 / 390 / 720px 三種寬度下**皆無溢出**;目前最寬的一行是
細雨如織的「劍意消耗 −55%」(7.2 / 9.2)。

## 三、其他文案欄位

- `name`:2–4 全形字,對仗優先。
- `rune`:1 字,取 `name` 中最有代表性的那個字。
- 轉世閣 `description`:目前無硬上限(版面可換行),但仍建議 ≤ 24 字,句式統一為
  「每階令……」或「開局……」。
