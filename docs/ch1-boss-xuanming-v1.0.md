玄冥墨蛟 BOSS 設計 v1.0

總共三境，不建議單純用 70%、35% 強切，而是 血量門檻＋完成當前招式後轉階段，避免王在動畫中突然變身。

第一境：游墨

100%～70%

玩家先認識牠的基本移動與攻擊方式。

第二境：潛淵

70%～35%

開始墨化、假身、潛入畫卷，閃避能力大幅提升。

第三境：玄冥

35%～0%

身體開始失去固定形體，戰鬥重心從「整條蛟」變成「捕捉蛟首」。

第一境「游墨」

第一境的玄冥墨蛟大部分時間維持你圖裡現在這種：

S 型盤旋姿態。

但不是停在中央。

牠會在畫面上半部緩慢游動。

大致活動區：

牠可以：

左上 → 中上 → 右上

以及稍微下降接近玩家。

但第一境不會跑到畫面下半部。

攻擊 01｜蛟首突

最基本的攻擊。

玄冥墨蛟停止游動。

頭部朝玩家方向轉動。

約 0.5～0.7 秒蓄勢。

接著：

整條身體突然拉直，蛟首高速衝向中心。

不是整隻王瞬移。

而是很像蛇攻擊獵物：

頭先衝出去，身體後段被拉長。

命中／攻擊結束後：

身體重新捲回上方。

這招最大的特色是：

攻擊期間牠不能閃避。

所以牠一旦決定咬下去，就必須承擔風險。

攻擊 02｜墨息

玄冥墨蛟仰頭。

嘴邊開始有黑墨聚集。

接著朝中心：

吐出一道持續約 1.5 秒的墨流。

不是火龍那種火焰。

視覺應該像：

大量濃墨被潑到宣紙上。

墨流會稍微左右擺動。

這招使用期間：

蛟首固定。

但長身仍然會緩慢扭動。

所以這是牠第一境最大的攻擊空窗。

攻擊 03｜墨尾掃

不是用實體尾巴打。

因為牠後半段本來就接近墨霧。

玄冥墨蛟突然扭轉身體：

      頭
       ╲
        ╲
       ╱
──────墨尾

尾部拉出一道巨大半月墨痕。

墨痕形成後：

脫離身體，朝中心掃過去。

所以會看到：

蛟身甩動 → 墨跡形成 → 墨刃飛出。

這非常符合牠現在的水墨造型。

攻擊 04｜墨珠

玄冥墨蛟繼續游動，不停下。

嘴裡連續吐出三顆：

濃縮墨珠。

第一境排列比較簡單：

左 → 中 → 右。

然後三顆墨珠先浮在空中約 0.5 秒。

再：

依序射向中心。

所以這是一個牠可以「邊移動邊使用」的低風險攻擊。

第一境的閃避

第一境只給牠兩種。

否則一開始就會太煩。

閃避 A｜扭身

御劍即將打到蛟首。

玄冥墨蛟：

頭往旁邊一甩。

身體形成一個很大的 S。

攻擊從頭旁邊飛過。

它不是瞬移。

所以玩家可以看到：

牠真的把頭躲開了。

閃避 B｜游離

如果攻擊量比較大：

玄冥墨蛟整條身體往左／右快速游動。

例如：

       BOSS
        ←←←

          ↑
         攻擊

留下淡淡墨影。

但是有一條重要規則：

連續閃避最多兩次。

第三次攻擊不允許再次游離。

否則會變成很惱人的王。

第一境防禦｜盤首

當玄冥墨蛟短時間受到大量攻擊：

牠不一定躲。

而是突然：

把長身盤起來。

       ╭─────╮
      │  頭   │
       ╰─────╯

身體外圈把蛟首包住。

這時：

外層軀體減傷約 60%。

不是無敵。

持續約 1.5 秒。

然後牠一定從盤身狀態接一招。

例如：

盤首 → 墨尾掃

所以這不是單純拖時間，而是「防禦 → 反攻」。

再一路往頭部墨化。

只剩下一團巨大的暈墨。

你看不到完整身體。

但潛墨不能超過約 2 秒。

否則就是純拖時間。

攻擊 05｜破墨

潛墨狀態的主要攻擊。

玩家周圍某方向突然：

墨色加深。

約 0.6 秒。

接著：

蛟首直接從那一塊墨裡衝出。

龍頭 → 穿過中心 → 化墨消失。

這一招甚至不需要完整身體出現。

只有：

蛟首＋一小段身軀。

所以第二境開始會明顯變得更凶。

攻擊 06｜雙蛟影

玄冥墨蛟從墨中浮出。

但這次：

左右各出現一條。

   墨蛟               墨蛟

              玩家

接著一起游動。

約 1 秒後：

其中一條突然化墨。

另外一條：

蛟首突。

下一次使用時則不一定哪一條是真的。

這是「墨蛟」非常適合的欺騙技能。

這招我會保留，而且讓它成為玄冥墨蛟的招牌技能。

牠不再只待在上半部。

第三境「玄冥」

HP 35%。

這次不要再讓牠單純變快。

真正的變化是：

玄冥墨蛟已經維持不了完整身體。

牠的尾巴首先完全消失。

中段也開始散成墨。

最後畫面裡看到的是：

清晰的蛟首

＋

半實體的頸部

＋

大量拖曳墨流。

就跟你現在這張圖本身的墨化感進一步放大。

第三境核心規則

第三境：

蛟首 = 核心實體。

軀體大部分變成墨氣。

因此牠的防禦思路完全改變。

第一、二境是：

躲掉攻擊。

第三境是：

讓你根本抓不到真正實體。

攻擊 09｜玄冥貫

這是蛟首突的最終版本。

墨蛟完全消失。

只剩：

一道高速移動的墨線。

突然：

蛟首從墨線前端形成。

直接穿過中心。

然後：

另一邊再次化墨。

一次使用可以：

連續 3 次。

例如：

左上 → 中心

右上 → 中心

正上 → 中心。

第三次結束後：

蛟首會有短暫停頓。

攻擊 10｜玄冥息

第三境主大招。

玄冥墨蛟出現在正上方。

身體後方大量墨氣：

全部被吸進嘴裡。

畫面甚至會產生「整幅畫的墨都在往牠嘴裡流」的感覺。

蓄力完成：

一道非常粗的：

玄墨洪流

直灌中心。

與普通墨息最大差別：

普通墨息是攻擊。

玄冥息則像：

把畫面撕開一道黑色裂口。

持續約 2～3 秒。

而且這段時間：

牠不能散墨、不能潛墨、不能閃避。

這才像真正的大招。

第三境的閃避機制

這時不能再大量使用普通左右游動。

改成：

「化墨換位」

蛟首受到高威脅攻擊：

頭部瞬間：

炸成一團墨。

約 0.4 秒後：

另一團墨裡重新長出蛟首。

但必須有明確的：

消失位置 → 墨流 → 出現位置

不要純瞬移。

玩家才看得懂。

第三境的防禦｜藏首

第三境最大的防禦招。

玄冥墨蛟察覺自己受到大量攻擊。

牠直接：

把蛟首縮進自己的墨雲。

畫面留下巨大的：

      墨
   墨墨墨墨
  墨墨墨墨墨
   墨墨墨墨
      墨

裡面可以看見龍形輪廓快速游動。

持續約 1.5 秒。

這段時間：

沒有有效弱點。

但結束時蛟首一定會從墨雲某一側衝出。

所以：

防禦本身就是下一次攻擊的前搖。

這樣不會變成無聊的無敵時間。

最後 10%「困獸」

我仍然建議保留特殊瀕死狀態，但這次配合牠的造型重新做。

10% HP 時：

玄冥墨蛟不再潛墨。

因為：

牠的墨已經快耗盡。

身體重新凝聚成比較完整的蛟形，但比最初更加破碎。

這時：

散墨：停用

潛墨：停用

假身：停用

藏首：停用

牠失去所有逃生方式。

換來：

所有進攻招式連接速度大幅提高。

最後循環可以變成：

蛟首突
→ 墨尾掃
→ 墨息
→ 蛟首突
→ 盤天
→ 玄冥貫
→ 玄冥息

變成真正的困獸之鬥。

這樣最後階段的感覺會非常好：

前面是「抓不到牠」。

最後變成「牠不躲了」。

我認為這版就比較接近你圖中的 玄冥墨蛟本身了，而且有一個很重要的特色：三個階段不是單純「技能越來越多」，而是牠的生存方式一直改變。

第一境牠靠身體游動生存；第二境靠融入墨中生存；第三境靠失去實體生存；瀕死時則乾脆放棄生存，全攻擊。這樣這隻王才會有完整的性格和戰鬥弧線。
