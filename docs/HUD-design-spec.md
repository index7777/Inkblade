# 墨劍訣 HUD 設計與落地規劃

> 狀態：正式規範 1.1  
> 基準畫面：直式 1080×1920；實作須依 HUD 容器寬度等比例縮放，並保留 44px 最小觸控區。  
> 視覺關鍵字：墨、紙、破、斂鋒。

## 1. 設計目標

HUD 必須像直接寫在畫卷上的墨跡，不使用現代玻璃面板、規整圓角卡片或霓虹光框。玩家在一眼內應能分辨：左上角色狀態、中上境界時限、右上操作與本境目標、左下劍訣入口。

資訊優先順序：

1. 神識與倒數；
2. 劍意與本境斬妖進度；
3. 道行；
4. 御劍、靜觀、劍訣等操作入口。

## 2. 配色

| 用途 | 色彩 | 建議值 |
|---|---|---|
| 主墨 | 墨黑 | `#1e1c19` |
| 次墨 | 暖灰黑 | `#302d29` |
| 紙色文字 | 米白 | `#eee5d3` |
| 神識 | 朱紅 | `#b63b31` |
| 劍意 | 青藍 | `#61abc0` |
| 道行 | 灰褐 | `#a49a82` |
| 警示 | 朱砂紅 | `#a9342c` |
| 就緒高亮 | 暗金 | `#c39a4b` |

紅、藍、金都有功能含義，不作無目的裝飾。劍訣是純介面入口，不使用朱砂點、金色高亮或冷卻灰階。

## 3. 字體

- 名稱與標題：毛筆或手寫書法風格；目前使用 `Noto Serif TC / STKaiti / KaiTi` 回退鏈。
- 數值與倒數：穩定襯線字，使用等寬數字特性，確保跳秒時不位移。
- 同一元件不可混用兩種書法風格。
- 小字不得低於 11px；關鍵狀態在手機基準不得低於 13px。

## 4. 元件系統

### 4.1 狀態條

結構：`黑灰墨刷底 → 功能色填充 → 標籤與數值`。

- 1080 基準尺寸：360×24，寬度約畫面 33.3%。
- 每列獨立成筆，不使用包住三列的大面板。
- 標籤與數值壓在墨刷之上；未填滿區保留黑墨。
- 起筆厚、收筆帶乾筆分岔；三列的高度與垂直間距一致。
- 神識朱紅、劍意青藍、道行灰褐。

### 4.2 圓形墨鈕

結構：`深墨團底 → 不規則雙墨圈 → 米白文字或圖示`。

- 大按鈕：140×140，約畫面寬 13%。
- 小按鈕：80×80，約畫面寬 7.4%，但觸控熱區至少 44px。
- 不使用規整 CSS 邊框圓；雙圈要有不同偏心與粗細。
- 預設：深墨底與米白字。
- 按下：縮至 94–95%，整體略暗。
- 冷卻與金色就緒僅供真正的戰鬥技能使用。
- 御劍、靜觀共用雙重不規則墨圈外框，中央透明露出畫卷；御劍仍保留原有啟用動畫。
- 左下劍訣的層次固定為「中央獨立黑色圓底 → 透明間隙（必須看得到畫卷背景）→ 外側粗偏心乾墨圈」。不得用白色或米灰圓線假裝間隙。只有預設與按下兩態，右上不得出現朱砂通知點，也沒有高亮、呼吸或冷卻。
- 「劍訣」白字必須完整收在中央黑圓內，四周保留清楚墨底，不得碰到或超出黑圓邊界。

### 4.3 橫向墨牌

用於境界與斬妖資訊。外形為窄長破邊墨刷，不裁成明顯六角形。

- 境界牌置中上方，墨底米白字；倒數獨立置於下方。
- 斬妖牌置於御劍、靜觀下方，只顯示標題及 `本境斬妖 / 目標`。
- 斬妖標題與數值間有一條低對比墨線。
- 數值右側使用小朱砂三角作目標指示，不使用骷髏。

## 5. 版面配置

```text
左上：神識／劍意／道行    中上：第 N 境＋倒數    右上：御劍／靜觀
                                                   斬妖數 N / N


左下：劍訣
```

- 各區獨立定位，不再為了切齊底線而動態拉大狀態條行距。
- 中央境界牌不得壓住左上量表；兩者至少保留畫面寬 1.5% 的空隙。
- 左上計量條、中上第 N 境、右上御劍／靜觀的視覺上緣必須共用同一條 HUD 基準線。
- 斬妖數墨牌的左右邊界必須與上方御劍／靜觀按鈕組的最左、最右邊界對齊。
- HUD 不得遮住中央玩家、主要劍令區及 Boss 血條。
- 安全區須包含瀏海與底部手勢列。

## 6. 戰鬥規則對應

- 每境有本境斬妖目標和時間限制。
- 普通境基準時間 45 秒；達標立即進下一境。
- 時限歸零仍未達標，本局失敗。
- 第 60 境為 Boss，斬妖目標為 1，使用較長的 Boss 時限。
- 右上顯示本境進度；總斬妖只保留在結算與紀錄，不占常駐 HUD。

## 7. 劍訣面板

- 左下劍訣按鈕打開面板時暫停戰鬥。
- 面板列出本局三選一中已習得的全部劍訣。
- 依劍式、劍勢、劍意、修持、真意分類。
- 對玩家只顯示一階、二階、三階；內部五級數值映射到三個顯示階段。
- 關閉可點右上叉號或面板外暗區。

### 7.1 三選一悟道卡

- 卡片左上使用不規則雙墨圓印，只放單字類別：劍陣「陣」、劍行「行」、劍痕「痕」、劍稟「稟」、真意「意」。
- 卡片右上以直書顯示選擇後階級：「一階」至「五階」。不顯示小成、大成、圓滿。
- 卡片中央大字必須取自遊戲設計名稱的第一個字；例如「齊鋒陣」顯示「齊」，不得另外使用一套無關符印字。
- 大字下方中標完整顯示遊戲設計名稱，再往下排列文字說明。劍陣名稱統一使用「陣」，不得顯示舊稱「式」。
- 滿五階技能由抽卡規則排除，不再出現在三選一。
- 卡片取消稀有度標籤、彩色文字與彩色邊框，所有資訊使用中性墨色。
- 卡片底、左上類別圓印與右上階級紙籤必須是三張獨立透明 PNG 素材，不得再用 CSS 框線假造材質。
- 卡片底紙與階級紙籤不可出現黑色矩形框線；材質必須是扁平舊書頁／舊畫卷，不可有羊皮紙式圓角、燒邊、浮雕、捲角或立體厚度。四周保留近方角的磨損纖維、缺口與墨灰舊痕。
- 卡片說明文字的左邊界不得超出左上類別圓印的左邊界。
- 重鑄按鈕使用與卡片相同的扁平舊書頁材質，不使用現代圓角、框線或浮起陰影。
- 三選一上方劍意帳使用與第 N 境一致的無框乾筆黑墨底，不使用規整描邊框。

## 8. 劍令視覺

劍令同時是輸入、飛行路徑和主要視覺，不畫成細滑鼠線：

- 一層淡墨滲邊；
- 一層有壓力變化的濃墨主筆；
- 兩側少量斷續乾筆絲；
- 收筆保留朱砂方向箭頭；
- 超出可支付劍意的區段改用暗金警示，收筆時仍會截斷。

## 9. 參考圖還原流程（強制）

日後收到 HUD 示意圖時，必須依下列順序製作，不得只憑印象用幾何 CSS 近似：

1. **拆件分析**：逐一量出外框比例、筆刷厚度、起收筆、留白、文字區、數值區、分隔線及各元件間距；文字與圖示不從參考圖照抄。
2. **取得無字底材**：優先以 SVG／Canvas 描摹；若筆觸仍不像參考圖，使用圖像生成製作同輪廓的純黑筆刷，或由使用者提供的圖去背擷取。生成時使用單一純色背景、單一孤立元件、無字、無圖示、無陰影。
3. **透明化與裁切**：以色鍵去背，清除綠邊或白邊，再依 Alpha 邊界裁掉所有多餘留白；原始生成檔保留，遊戲只引用裁切後的透明 PNG。
4. **動態層分離**：筆刷 PNG 只作底框／裁切圖層；名稱、即時數值、倒數、填充比例、分隔線及紅三角全部維持 DOM／Canvas 動態層，不烘焙進圖片。專案必須支援 `file://` 直接開啟，因此不得依賴瀏覽器會阻擋的外部 PNG CSS mask；改用一般背景圖、寬度裁切與色彩濾鏡。
5. **尺寸還原**：依參考圖的寬高比與相對間距放回指定錨點。計量條、第 N 境、斬妖數分別使用獨立素材，不可用同一幾何形硬套。
6. **實機自證**：必須實際進入遊戲，在目標直式尺寸自行截圖並親自查看；逐項比對位置、比例、墨色、筆觸、文字可讀性與安全區。沒有看過截圖不得交付；看完仍不符合也不得交付，必須繼續修改再截圖。
7. **留存驗收物**：保存最終截圖及所用素材，並在變更紀錄中註明來源方法（描摹、生成或去背）與版本。

本次固定資產：

- `assets/ui/hud-meter-brush.png`：左上三列計量條共用的透明筆刷 mask。
- `assets/ui/hud-realm-brush-v2.png`：中上「第 N 境」暖灰淡墨筆刷底。
- `assets/ui/hud-score-brush-v2.png`：右上「斬妖數」暖灰淡墨框。
- `assets/ui/hud-swordarts-center-master.png`：直接由使用者提供母版拆出的中央黑圓；不重新生成、不調色。
- `assets/ui/hud-swordarts-ring-master.png`：直接由同一母版拆出的乾墨外圈；不重新生成、不調色，且不得與中央黑圓合併。

## 10. 實作策略

- 狀態條使用透明 PNG 一般背景圖配合寬度裁切與色彩濾鏡，讓 `file://` 可用並保持乾筆輪廓。
- 圓形墨鈕使用 CSS 深墨底搭配不規則 SVG 墨圈；文字與狀態保持 DOM 動態層。
- 境界、斬妖與技能數值不可烘焙進圖片。
- 劍令使用 Canvas 即時分段繪製。
- 若後續換成透明 PNG，必須維持相同尺寸比例與狀態接口。

## 11. 驗收清單

- [ ] 左上三列皆為獨立墨刷，文字與數值可讀。
- [ ] 中上境界牌不與左側量表重疊。
- [ ] 倒數跳秒時不左右抖動，最後十秒轉朱砂警示。
- [ ] 右上斬妖牌為破邊矩形，不是六角形。
- [ ] 劍訣位於左下，尺寸約畫面寬 13%。
- [ ] 劍訣沒有朱砂點、冷卻、高亮或呼吸動畫。
- [ ] 御劍、靜觀為透明中央的雙重不規則墨圈；左下劍訣使用黑色圓底。
- [ ] 已進入遊戲自行截圖，並逐項與參考圖比對；未通過不得交付。
- [ ] 劍訣面板能正確分類並顯示一至三階。
- [ ] 畫線時劍令能讀成毛筆墨跡，而非平滑細線。
- [ ] 360、525、941、1080 寬度皆無 HUD 重疊或超出安全區。

### 11.1 手機安全邊界與斬妖數互動（2026-08-10）

- 左側計量條距畫面左緣至少 `max(3cqw, 14px)`；三選一卡片容器左右至少保留 `max(4cqw, 18px)`，文字與互動內容不可進入危險區。
- 斬妖數的數字必須以墨刷底圖本身為中心；紅三角獨立絕對定位於數字右側，不得參與數字置中計算。
- 數字層級低於標題，使用 `clamp(13px, 2.6cqw, 20px)`，不可用展示標題的大字比例。
- 紅三角必須是至少 28×28 px 的真實按鈕；收合時箭頭朝下、展開時朝上。點擊可展開／收合本境的尚餘妖數與剩餘時間，面板寬度為斬妖墨底的 135% 且右緣對齊，並同步可存取狀態。
- 每次調整都必須以 525×923 手機視窗重新截圖，並親自點擊檢查展開與收合；不符合不得交付。
