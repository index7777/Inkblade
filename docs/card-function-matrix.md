# 全卡片功能與相容／互斥矩陣

> 來源：`data/game-config.js`，更新於 2026-08-11。

## 已實裝硬規則

1. 開局四選一劍陣；未選陣不能繼續，一局只走該陣。
2. 劍痕四選一：墨痕、蝕痕、鎮痕、斷痕。第一張確定路線後，其餘三張不再出現；定路前可用重鑄換牌。
3. 劍型三選一：養鋒、展鋒、斂鋒。第一張確定路線後，其餘兩張不再出現；定路前可用重鑄換牌。
4. 劍稟沒有擇一，可全部升滿；第一張劍稟會成為修煉重心，後續出現權重乘 1.75。
5. 開匣已暫時移除；轉世閣的劍匣初開也已移除。
6. 重塑保留開局劍陣，清除劍痕、劍型鎖定與劍稟首選權重。

## 真意（主動大招）

共通消耗 200 劍意、冷卻 30 秒；不進普通悟道池。劍陣滿 5 階後，從轉世閣已永久解鎖的真意中 N 選 1，當局鎖定。

| 真意 | 功能 | 持續 |
|---|---|---|
| 萬劍歸宗 | 人物中心落下劍雨，同心向外擴散 | 瞬發 |
| 一筆開天 | 巨劍由下往上，左右展開持續劍氣 | 瞬發 |
| 歸藏無痕 | 全劍 360° 射出至邊緣再折返 | 10 秒 |
| 環月歸墟 | 全劍環月旋轉，總劍速轉為傷害 | 10 秒 |

## 尚待決定的 A／B 關係

目前不再需要討論展鋒／斂鋒或四種劍痕彼此是否相容，因為已由分類鎖路解決。仍待整理的是跨分類組合，例如「引鋒不能暴擊」與凝神的效益、各主動真意和四座劍陣的招式表現；這些不應先用硬互斥掩蓋，需逐項確認玩法。
