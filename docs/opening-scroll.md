# 墨劍訣 · 開場畫卷展開(Opening Scroll)規劃

> 狀態:**規劃/待實作**。點「入局」後播放的過場,約 3 秒。此檔只記做法,尚未寫進 inkblade.html。

## 目標體驗(約 3 秒,分四階段)

### 1. 桌面出現
- 全畫面生成式木桌/書案背景。
- 中央放一卷閉合的橫向畫卷。
- 周圍暗色景深,集中視線。

### 2. 畫卷開始展開
- 上、下捲桿起初重疊在畫面中央。
- 上捲桿向上移、下捲桿向下移。
- 兩桿之間的宣紙區域同步從中央向上下揭露。
- **用遮罩逐步顯示真正的遊戲底圖**,不是另放一張過場圖。

### 3. 遊戲世界浮現
- 展開前段先顯示模糊山水;隨畫卷張開由模糊變清晰。
- 主角以淡墨聚合方式出現。
- HUD 最後才淡入(避免一開始資訊太多)。

### 4. 進入遊戲
- 桌面背景逐漸變暗、模糊。
- 畫卷放大到目前 9:16 遊戲尺寸。
- 捲桿停在上下邊緣。
- **動畫完成後才解除 `G.paused`、開始生怪與計時。**

## 技術結構
```
桌面背景
└─ 開場畫卷容器
   ├─ 上捲桿(現有生成素材)
   ├─ 遊戲畫面遮罩
   │  ├─ 模糊景深
   │  ├─ 遊戲底圖
   │  └─ Canvas
   └─ 下捲桿(現有生成素材)
```

## 動畫重點
- 捲桿用 `transform: translateY()`(效能穩定)。
- 遊戲畫面用 `clip-path: inset()` 從中央揭露。
- 紙張陰影隨展開範圍增加。
- Canvas 從一開始就存在,只是暫停並被遮罩(不重載頁面,過場與遊戲不跳畫面)。
- 點「入局」後播放;再次遊玩可縮短或直接略過。
- 支援 `prefers-reduced-motion`:低動態模式直接淡入。

## 與現有程式的接點(實作時)
- 觸發:`start()` 內、解除 `G.paused` 之前先跑過場;過場結束的 callback 才 `G.paused=false` + 開始生怪/計時。
- 底圖:遊戲底圖用現有 `#paper`(`assets/scenes/level01-bg.png`);模糊山水可用同圖加 `filter:blur()` 漸解。
- 直式:目標 9:16(1080×1920)。
- 待補素材:木桌/書案背景、上/下捲桿(生成式);可暫用程序化色塊佔位。
- 「再玩略過」:用一個 flag(如 `meta` 或 sessionStorage)記錄已看過,之後縮短/跳過。
