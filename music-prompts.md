# 墨劍訣 · Inkblade — 背景音樂提詞

適用 Suno / Udio 等 AI 音樂工具。共通基底:水墨仙俠,古琴古箏笛簫二胡琵琶為骨,依場景疊加大鼓或空靈氛圍。避免人聲加 `instrumental only`。

## 主選單 / 標題
留白、悠遠、宣紙上一滴墨暈開的靜。
```
Traditional Chinese wuxia ambient, solo guqin and bamboo dizi flute, sparse and meditative, distant temple bell, soft wind and water textures, ink-wash serenity, cinematic and spacious, no drums, 60 BPM, loopable
```

## 戰鬥 / 一般波次
御劍疾行、愈殺愈快的驅動感。
```
Chinese wuxia battle theme, driving taiko and frame drums, energetic erhu and pipa melody, dizi flute flourishes, hybrid orchestral strings with subtle electronic pulse, heroic and relentless, building intensity, 140 BPM, seamless loop
```

## 高波次 / 危急
妖潮壓境、緊繃。
```
Intense Chinese orchestral wuxia, fast staccato strings, thunderous war drums, urgent suona and pipa, dissonant tension, dark and dangerous, adrenaline, 160 BPM, loopable
```

## 悟劍訣 / 升級選卡(短 stinger)
```
Short magical stinger, shimmering guzheng glissando, bright bell chimes, uplifting Chinese fantasy flourish, sense of enlightenment, 3 seconds, one-shot
```

## Boss / 大妖
```
Epic Chinese wuxia boss battle, massive taiko drums and gongs, aggressive erhu and suona, choir chants, cinematic hybrid orchestra, ominous and grand, 150 BPM, loopable
```

## 隕落 / 轉世
先哀婉散去,後轉為輪迴新生。
```
Melancholic to hopeful Chinese wuxia piece, mournful solo xiao flute and guqin, soft strings swelling into gentle warmth, theme of death and reincarnation, ink fading and reforming, cinematic, 70 BPM
```

## 轉世閣 / 商城
靜謐、內斂、耐聽。
```
Calm Chinese ambient menu music, gentle guzheng and pipa arpeggios, warm pad, incense-quiet atmosphere, contemplative, unobtrusive, 80 BPM, long loop
```

## 調校小技巧
- 旋律太滿:加 `minimal, sparse`
- 更現代/年輕向:加 `lo-fi` 或 `modern hybrid`
- 要純東方:加 `no western instruments`
- 無人聲:加 `instrumental only`
